# Accessibility Statement

**App:** SuryaSetu (“the App”), published by [Legal entity name]
**Last reviewed:** [Effective date]

We want everyone on a solar team, in the office or on a rooftop, to be able to use the App. This statement says honestly what works today and what does not. The App has **not** been formally audited against WCAG 2.1 or 2.2, and we do not claim conformance.

## What works today

- **Keyboard use.** Menus, buttons, links, form fields and dropdowns are standard HTML controls, so they work with Tab, Shift+Tab, Enter and Space. Buttons keep the browser’s visible focus outline; form fields show a coloured focus ring.
- **Board views without dragging.** On drag-and-drop boards (for example the leads pipeline), each card also has a **Move** dropdown, so you can change the stage with a keyboard or a screen reader instead of dragging.
- **Labels.** Form fields have visible text labels that are linked to the field. Required fields are marked.
- **Error messages** and status messages (for example “Loading…”, sign-in errors, form errors) are announced to screen readers.
- **Charts** have a text label for screen readers (the donut chart’s label includes the values), and the same numbers are available in list, pivot and report views, so the information is not only in shapes or colours.
- **Light and dark mode.** The App follows your phone or computer setting. You can also choose Light, Dark or System in **Settings → Appearance**.
- **Phones.** Text boxes use a 16 px font on screens up to 900 px wide, so iPhones do not zoom in when you tap a field. The layout adapts to small screens: the module tabs move below the top bar, and icon-only buttons such as Home (“All apps”) and Alerts have text labels for screen readers.
- **Zoom.** You can zoom the page with the browser or pinch-zoom; the App does not block it.
- **Language** of the page is set (English), which helps screen readers pronounce text correctly.
- **Printed documents** (quotations, invoices, receipts, certificates) use dark text on a white page, whatever the App’s theme.

## Known gaps

- No “skip to main content” link yet, so keyboard users tab through the menu on every page.
- Base text size is 15 px on large screens. Use browser zoom if you need larger text.
- Map views show customers as points on a map. Use the list view for the same information as text.
- Hover-only details on charts are not available to keyboard users; use the pivot or list view.
- Small buttons (“sm”) are 30 px tall, which meets the WCAG 2.2 minimum target size but is smaller than the 44 px often recommended for touch.
- The App’s small animations do not yet respect the “reduce motion” setting.
- Colour contrast has been chosen with care but has not been measured on every screen and badge.
- The App has not been tested end to end with TalkBack, VoiceOver or NVDA.
- English only. No Hindi or other Indian-language interface yet.
- Long tables scroll sideways on phones.
